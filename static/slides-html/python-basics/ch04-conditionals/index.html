第一章：天秤上的比較——程式如何判斷是非？

在進入分支決策之前，電腦必須具備度量衡與辨明真偽的能力。在 Python 中，所有比較操作本質上就像是一座精密的天秤：天秤兩端擺上資料，檢測完畢後，只會產生兩種不可撼動的結果之一：True（真）或是 False（假）[cite: 6]。這種純粹的布林型態（Boolean），正是所有流程決策的起點[cite: 6]。

1-1 大於、小於與相等：認識 6 大比較運算子

Python 提供了 6 種最基礎的天秤量尺，用於數值與資料的比較[cite: 6]：

pythoncomparison_demo.py
score = 85

print(score > 60)
print(score < 50)
print(score >= 85)
print(score <= 80)
print(score == 85)
print(score != 100)

1-2 新手避坑第一關：貼標籤「=」與量天秤「==」的致命混淆

⚠️ 零基礎避坑提醒：
初學者最常犯的錯誤，就是把數學上的「等於」習慣寫成單一個等號 =。
請在黑板上為學生建立堅固的心智模型：
  • 單等號 =（賦值 Binding）：是「繫上名牌吊牌」，把變數名稱綁定到右側物件。
  • 雙等號 ==（比較 Comparison）：是「拿出天秤比對」，詢問直譯器左右兩側的值是否相同[cite: 6]。
如果在條件判斷裡誤寫為 if x = 5:，直譯器會無情地回報 SyntaxError: invalid syntax 語法錯誤！

第二章：邏輯的交集與捷徑——讓電腦學會多重思考

日常生活中，事件的發生往往取決於多項條件。在 Python 中，我們使用三大邏輯安檢門：and、or、not[cite: 6]。

2-1 打造邏輯安檢門：真值表一覽

條件 A 運算子 條件 B 計算結果 白話口訣
True and True True 雙方都成立，才算過關[cite: 6]
True and False False 只要有一方不合，立刻失敗[cite: 6]
True or False True 只要有一方成立，大獲全勝[cite: 6]
False or False False 兩邊都落空，才是真的失敗[cite: 6]
True not — False 黑白反轉，顛倒真偽[cite: 6]

2-2 偷懶的直譯器：透視「短路評估（Short-circuit Evaluation）」行為

直譯器計算複合邏輯時，若左側的結果已經足以拍板定案，直譯器就絕對不會浪費半毫秒運算力去讀取右側條件[cite: 6]！

第三章：人生十字路口——條件分支結構 (if / elif / else)

學會了是非判斷，我們就能指引 Python 走向不同的程式區塊。Python 的條件分支結構就像是單向鐵路調車場的轉轍器，引導載貨列車駛入指定的軌道[cite: 6]。

3-1 單向通行證：if 條件門檻

只有滿足條件時，才會執行特定動作；不滿足就當作沒事發生[cite: 6]：

pythonsingle_if.py
age = 18

if age >= 18:
    print("你已經成年")

3-2 雙向叉路：if...else 的二分世界

非此即彼，兩個區塊必定擇一執行，絕不可能同時跳過或同時發生[cite: 6]：

pythonif_else.py
age = 16

if age >= 18:
    print("你已經成年")
else:
    print("你還未成年")

3-3 多線分流站：if...elif...else 的互斥階梯與順序陷阱

當面臨 3 種以上的分流時，使用 elif[cite: 6]。請務必向學生強調：這是一座由上而下的互斥階梯，一旦上方有任何條件命中，整座階梯立刻結案，下方所有的 elif 和 else 都會被指令指標直接跳過（Bypass）！[cite: 6]

第四章：簡潔與層次——條件運算進階技巧

4-1 單行條件運算（三元運算子）

當只有單純的二選一賦值需求時，Python 支援將 if-else 寫成精巧的一行表達式[cite: 6]：

變數 = 真實結果 if 判斷條件 else 虛假結果

pythonternary_demo.py
is_adult = True
status = "成人" if is_adult else "未成年"
print(status)

4-2 條件搭配多重邏輯（and / or 複合安檢）

多個條件可以使用括號與邏輯運算子組合，建立多重把關的安檢門檻[cite: 6]：

pythoncombined_conditions.py
temperature = 30
weather = "晴天"

if temperature > 25 and weather == "晴天":
    print("天氣很好，適合外出")
else:
    print("天氣不太好")

第五章：新手避坑指南——這些報錯你遇到了嗎？

5-1 縮排（Indentation）的魔咒

在 Python 中，直譯器完全依賴「看不見的空白縮排」來識別程式碼的從屬結構！

pythonindentation_error.py
# 錯誤示範：忘記縮排
if 5 > 3:
print("這行會直接噴 IndentationError！")

# 正確規範：縮排統一使用 4 個半形空白，切勿混用 Tab

5-2 忘記冒號「:」的抓蟲日常

if、elif、else 行尾的冒號代表「向直譯器宣告：後方即將進入從屬區塊」。漏掉冒號會立即引發 SyntaxError: expected ':'。

第六章：任務挑戰時間——打造你的自動決策工具

任務一：數值正負零判定機

規則說明：撰寫程式，根據用戶輸入的整數判斷它是正數、負數還是零[cite: 6]。

pythonnumber_sign_solution.py
num = int(input("請輸入一個數字："))

if num > 0:
    print("這是一個正數")
elif num < 0:
    print("這是一個負數")
else:
    print("這是零")

任務二：曆法推算員——「閏年判定系統」

規則說明：公曆閏年規則如下：能被 4 整除且「不能被 100 整除」，或能被 400 整除者為閏年，其餘為平年[cite: 3, 6]。

pythonleap_year_solution.py
year = int(input("請輸入年份："))

if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print(f"{year} 是閏年")
else:
    print(f"{year} 不是閏年")

任務三：成績等第評定系統

規則說明：根據用戶輸入的成績（0~100），輸出對應的等級（A, B, C, D, F）[cite: 3, 6]。

pythonscore_evaluator_solution.py
score = int(input("請輸入成績："))

if score >= 90:
    print("等級 A")
elif score >= 80:
    print("等級 B")
elif score >= 70:
    print("等級 C")
elif score >= 60:
    print("等級 D")
else:
    print("等級 F")
