Lesson7. 字典（Dict）與集合（Set）

掌握 Python 的鍵值對容器字典與無序集合，學習高效的資料查找、去重複與集合運算。

📅 Thursday, September 17, 2026 Public Python Basics

7-1 字典本質與雜湊映射機制

若將串列（List）視為依照整數編號排隊的儲物櫃，字典（Dictionary）則是以專屬「識別標籤（Key）」進行物件對映的關聯儲存系統。

在底層實作上，Python 字典採用雜湊表（Hash Table）架構。當直譯器存取一個鍵（Key）時，會透過雜湊運算換算記憶體槽位，使字典在檢索、新增或刪除元素時，均能在平均 O(1) 的常數時間內完成。

1. 字典宣告與鍵的合法性規範

# 1. 字典字面值定義
student = {
"name": "小明",
"age": 18,
"grade": "高三"
}

# 2. 建立空字典的兩種方式
empty_dict_a = {}
empty_dict_b = dict()

# 3. 透過成對序列建構字典
pairs = [("id", 101), ("status", "active")]
user_info = dict(pairs)
技術核心：鍵（Key）的雜湊約束（Hashable）

字典的「值（Value）」可為任意型態且允許重複；但「鍵（Key）」具備絕對唯一性，且必須是不可變物件（Hashable），例如 str、int 或 tuple。若誤將可變物件（如 list）作為鍵，直譯器會立即拋出 TypeError: unhashable type: 'list'。

7-2 字典元素操作與安全讀取機制

字典是可變容器（Mutable）。使用 d[key] = value 語法時，若鍵已存在則會就地覆蓋更新；若不存在則會新增該筆項目。但在讀取與刪除時，必須格外防範因鍵不存在所引發的程式中斷。

2. 字典取值與刪除防禦性對照表

操作語法語法類別目標鍵存在時之行為目標鍵不存在時之行為回傳值處理

7-3 字典視圖與走訪解構

Python 提供了三種動態視圖物件（View Objects）：keys()、values() 與 items()。視圖物件會即時反映字典底層的變動，不需額外耗費記憶體進行複製。

student = {"name": "小明", "age": 18, "grade": "高三"}

# 1. 迭代所有的鍵（Keys）
for key in student.keys():
print("鍵:", key)

# 2. 迭代所有的值（Values）
for val in student.values():
print("值:", val)

# 3. 鍵值同步解構走訪（Items）
for key, val in student.items():
print(f"屬性 [{key}] -> {val}")

1. 串列包字典（List of Dicts）與庫存範例

# 模擬電商商品清單
inventory = [
{"id": "A01", "name": "機械鍵盤", "price": 2800, "stock": 12},
{"id": "A02", "name": "無線滑鼠", "price": 1200, "stock": 45},
{"id": "A03", "name": "人體工學椅", "price": 8900, "stock": 4}
]

total_valuation = 0
for item in inventory:
subtotal = item["price"] * item["stock"]
total_valuation += subtotal
print(f"商品：{item['name']} | 庫存總值：{subtotal} 元")

print(f"總庫存資產總值：{total_valuation} 元")

7-5 字典推導式運算（Dictionary Comprehension）

字典推導式能以一行簡潔的程式碼動態建立鍵值對應映射，並支援條件過濾：

# 1. 數值與平方的動態映射
numbers = [1, 2, 3, 4, 5]
square_map = {num: num ** 2 for num in numbers}
print(square_map)  # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# 2. 字母與 ASCII 碼映射（僅篩選偶數編碼）
letters = ["a", "b", "c", "d", "e"]
even_ascii_dict = {ch: ord(ch) for ch in letters if ord(ch) % 2 == 0}
print(even_ascii_dict)  # {'b': 98, 'd': 100}

7-6 集合本質與集合代數運算

集合（Set）是儲存「唯一、不可變元素」的無序容器。它就像是只有鍵而沒有值的雜湊結構。

1. 集合移除重複的特性與基本操作

# 利用 set 快速移除串列中的重複項目
raw_data = ["Python", "AI", "Python", "Web", "AI", "Cloud"]
unique_set = set(raw_data)
print(unique_set)  # {'Python', 'Cloud', 'AI', 'Web'}（無序）

unique_set.add("DevOps")     # 新增元素
unique_set.discard("Web")    # 找不到元素也不會引發錯誤的移除方法

2. 集合代數運算（交集、聯集、差集）

運算名稱運算子方法邏輯說明
交集 (Intersection)A & BA.intersection(B)同時存在於 A 與 B 的共同元素
聯集 (Union)A | BA.union(B)合併 A 與 B 的所有元素，重複者僅留一份
差集 (Difference)A - BA.difference(B)存在於 A 但排除掉存在於 B 的元素
對稱差集 (Symmetric Diff)A ^ BA.symmetric_difference(B)僅存在於 A 或 B 其中一方的元素
group_a = {"Python", "Git", "SQL"}
group_b = {"Python", "Docker", "AWS"}

print("共同掌握技能 (交集):", group_a & group_b)  # {'Python'}
print("整體技能清單 (聯集):", group_a | group_b)  # {'Python', 'Git', 'SQL', 'Docker', 'AWS'}
print("A 組獨有技能 (差集):", group_a - group_b)  # {'Git', 'SQL'}
