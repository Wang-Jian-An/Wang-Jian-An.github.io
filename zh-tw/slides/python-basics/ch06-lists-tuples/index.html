Lesson6：序列容器 —— 串列（List）與元組（Tuple）

學習 Python 最常用的序列容器：可變的串列與不可變的元組，掌握索引、切片與常見操作方法。

📅 Wednesday, September 16, 2026 🔒 Private Python Basics

6-1 序列容器特性與記憶體配置機制

在 Python 的記憶體架構中，串列（list）是一種高度動態的循序容器。直譯器底層配置的是一組連續的記憶體指標陣列（Array of Pointers）。每個槽位存放的均是指向實體物件的記憶體位址參照，而非直接把資料數值硬塞在槽位內。

串列三大核心特性

  • 有序性（Ordered）：元素嚴格依照插入順序分配循序編號（索引從 0 起算）。
  • 可變性（Mutable）：串列建立後，其長度與槽位指標可隨時原地替換，無需重新配置整個容器物件。
  • 異質性（Heterogeneous）：由於槽位中儲存的是物件指標，同一個串列內允許混合容納型態截然不同的元素。
# 範例 1：建立串列（包含異質元素與巢狀結構）
my_list = [10, 'Python', 3.14, [1, 2, 3]]
print(my_list)
終端機輸出
[10, 'Python', 3.14, [1, 2, 3]]

內建聚合量測函式

針對數值型序列，Python 提供多組 $O(n)$ 線性時間複雜度的原生統計函式：

# 範例 2：常用內建統計函式
numbers = [4, 7, 1, 12, 9]

print(len(numbers))  # 計算元素總量: 5
print(max(numbers))  # 取得最大值: 12
print(min(numbers))  # 取得最小值: 1
print(sum(numbers))  # 元素總和: 33

6-2 序列索引定址與切片邊界計算

直譯器為序列容器提供雙向對應定址：正向索引由 0 遞增至 N - 1；負向索引則自末端 -1 倒數至 -N。直譯器在解析負向索引 -k 時，內部等價執行 N + (-k) 計算真實位移。

切片左閉右開原理：[start:stop:step]

切片運算子並非單純取單一索引，而是在元素接縫處劃定分割邊界，嚴格遵循「左閉右開（含頭不含尾）」原則：

  • start：擷取的起始邊界索引（包含此位置）。
  • stop：擷取的終止邊界索引（不包含此位置）。
  • step：每次推進的步長；當步長為負整數時，直譯器逆向走訪。
# 範例 3：雙向索引存取與切片操作
animals = ['cat', 'dog', 'rabbit', 'horse']

print(animals[0])     # 正向索引取首位: 'cat'
print(animals[-1])    # 負向索引取末位: 'horse'
print(animals[1:3])   # 切片索引 1 至 2: ['dog', 'rabbit']
print(animals[:2])    # 省略起點，預設從 0 開始: ['cat', 'dog']
print(animals[2:])    # 省略終點，延展至序列結尾: ['rabbit', 'horse']
直譯器機制模擬：雙向尺規索引定址與切片投影儀

運算式：animals[ : : ]

6-3 串列元素動態操作與原地修改（In-place Modification）

串列支援豐富的原地修改方法。理解其運作機制的關鍵在於評估時間複雜度與記憶體搬移的效能成本。

新增元素：append()、extend() 與 insert()

  • append(x)：於串列末端追加單一元素指標，時間複雜度為分攤常數時間 $O(1)$。
  • extend(iterable)：逐一展開可迭代物件，整批追加至串列末端。
  • insert(index, x)：於指定索引插入新指標。為保持陣列連續性，目標索引後的所有槽位指標必須集體向右平移一格，時間成本為 $O(n)$。
# 範例 4：串列的新增操作
fruits = ['apple', 'banana']

fruits.append('cherry')
print(fruits)  # ['apple', 'banana', 'cherry']

fruits.insert(1, 'orange')
print(fruits)  # ['apple', 'orange', 'banana', 'cherry']

fruits.extend(['kiwi', 'mango'])
print(fruits)  # ['apple', 'orange', 'banana', 'cherry', 'kiwi', 'mango']

移除元素：pop()、remove() 與 clear()

  • pop([index])：移除並傳回指定索引位置的元素（預設為末位 -1）。若彈出非末端元素，後續槽位需左移遞補（$O(n)$）。
  • remove(val)：線性搜尋第一個數值相符的元素並移除；若不存在則拋出 ValueError。
  • clear()：將串列內所有參照指標清空，長度歸零重設為 []。
# 範例 5：串列的移除操作
numbers = [10, 20, 30, 40, 50]

numbers.remove(20)
print(numbers)  # [10, 30, 40, 50]

val = numbers.pop()
print(val)      # 傳回彈出值: 50
print(numbers)  # [10, 30, 40]

numbers.clear()
print(numbers)  # []
直譯器機制模擬：連續記憶體槽位動態增刪與實體推擠模擬器

6-4 序列排序演算法與原地異動評估

初學者最常混淆的關鍵，在於「原地修改方法」與「產生獨立副本的函式」的本質差異。Python 的 Timsort 演算法在此兩者有完全不同的記憶體分配策略。

原地排序 list.sort() vs. 獨立副本 sorted()

  • list.sort(reverse=False)：屬於物件方法。它直接在原串列的連續記憶體空間中進行指標重排。因為是原地異動，其回傳值固定為 None。
  • sorted(iterable, reverse=False)：屬於內建函式。直譯器會配置全新記憶體陣列，複製元素指標並完成排序後，回傳全新的獨立串列物件，原串列維持原封不動。
  • list.reverse()：原地翻轉方法，直接顛倒原串列槽位指標，回傳值同樣為 None。
# 範例 6：list.sort() 與 sorted() 之對比
scores = [85, 78, 92, 68]

# 1. 使用 sorted() 產生新副本，原串列完全不變
sorted_scores = sorted(scores)
print(sorted_scores)  # [68, 78, 85, 92]
print(scores)         # [85, 78, 92, 68] (維持原狀)

# 2. 使用 sort() 原地排序（注意：回傳 None）
scores.sort()
print(scores)         # [68, 78, 85, 92] (原物件已被修改)
避坑警示：常見初學者賦值陷阱

初學者極易誤寫 scores = scores.sort()。由於 sort() 為原地操作且不產生實體回傳值，此時 scores 變數將被綁定為 None，導致原有資料在變數範圍內被徹底覆蓋丟失！

6-5 元組特性與結構賦值

元組（tuple）使用小括號 () 定義。在直譯器內部，元組同樣配置連續槽位，但其被賦予了不可變性（Immutability）。一旦建立，該記憶體槽位即被唯讀封印，嚴禁新增、刪除或重新賦值。

唯讀防護與執行期安全

元組常用於儲存不應被竄改的關鍵資料（如經緯度座標、資料庫連線參數、RGB 色碼）。

# 範例 7：元組不可變性保護機制
coordinates = (10, 20)
print(coordinates[0])  # 讀取正常: 10

# 嘗試修改元組槽位會立即引發例外
# coordinates[0] = 5  # TypeError: 'tuple' object does not support item assignment

元組解構賦值（Unpacking）

Python 支援一行完成多變數對應拆解指派，當等號左側識別碼數量與右側元組長度一致時，直譯器會自動完成一對一的解構與綁定：

# 範例 8：元組解構賦值與快速交換兩數
point = (100, 200)
x, y = point
print(f"X: {x}, Y: {y}")  # X: 100, Y: 200

# 經典應用：無需中介暫存變數的數值互換
a = 1
b = 2
a, b = b, a  # 右側先封裝為 (2, 1)，隨即解構指派給 a, b
print(a, b)  # 2 1

6-6 宣告式序列建構：串列生成式（List Comprehension）

串列生成式並非呼叫外部函式，而是在方括號 [...] 內部形成封閉的記憶體建構空間。它由 C 語言層級原生迴圈驅動，比起傳統先建立空串列再逐次 append() 具有更高的執行效能。

方括號內的執行時序

  1. 迴圈走訪（右側）：for item in iterable 依序取出原料元素。
  2. 條件過濾閘門（中後段）：若宣告 if condition，立即檢驗元素是否符合資格，未通過者直接剔除。
  3. 運算式求值（左側）：通過閘門之元素送入最前端 expression 運算，求值後直接推入方括號內部的新槽位。
# 範例 9：串列生成式基礎與條件過濾
# 1. 計算 0 到 9 之平方數
squares = [x**2 for x in range(10)]
print(squares)  # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

# 2. 加入 if 條件：僅篩選偶數進行平方
even_squares = [x**2 for x in range(10) if x % 2 == 0]
print(even_squares)  # [0, 4, 16, 36, 64]

6-7 綜合實作評量

實戰任務一：班級成績統計與排序系統

題目需求：給定一組未經整理的學生期末成績串列，計算班級總分、平均分、最高分與最低分；產出由高至低的成績排行榜，同時確保原始串列紀錄不被覆蓋摧毀。

# 實作 1：班級成績全功能統計系統
scores = [85, 78, 92, 68, 55, 94]

# 1. 內建量測函式彙整統計
total_score = sum(scores)
count = len(scores)
avg_score = total_score / count
max_score = max(scores)
min_score = min(scores)

# 2. 產出排序獨立副本（降序），保護原資料完整
ranked_scores = sorted(scores, reverse=True)

print(f"班級總分: {total_score}, 平均分: {avg_score:.2f}")
print(f"最高分: {max_score}, 最低分: {min_score}")
print(f"名次排序 (高至低): {ranked_scores}")
print(f"原始登錄順序保持不變: {scores}")

實戰任務二：高效資料過濾器（串列生成式實務應用）

題目需求：給定原始商品定價數列，使用單一行「串列生成式」，篩選出所有大於等於 50 元的商品，並將其全部打 9 折（乘以 0.9）後轉為整數回傳。

# 實作 2：單行生成式處理
raw_prices = [12, 65, 48, 80, 95, 30, 100]

# 宣告式單行處理：過濾 >= 50 並進行 9 折轉換
discounted = [int(p * 0.9) for p in raw_prices if p >= 50]

print("原始價格清單:", raw_prices)
print("折扣篩選結果:", discounted)
