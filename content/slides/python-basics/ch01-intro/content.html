1. 變數定義、輸入、輸出及其格式化輸出

課程專用教材 ｜ 涵蓋 Python 直譯器底層執行機制與記憶體物件模型

一、輸出：print() 函數與標準輸出流

1. print() 函數運作機制

print() 是 Python 用於將資料寫入標準輸出流（Standard Output Stream, sys.stdout）的內建函數。執行時，Python 直譯器會依據下列步驟處理：

  1. 引數求值（Argument Evaluation）：對括號內的運算式或變數進行求值，從記憶體取得對應資料。
  2. 字串化轉換（String Conversion）：隱式呼叫物件的 __str__() 方法將資料轉換為字元流。
  3. 緩衝區輸出與刷新（Buffer & Flush）：將字元推送到 sys.stdout 緩衝區，並根據 sep 參數分隔多個引數，最後附加 end 參數（預設為換行符 \n）並輸出至終端機。

完整函數簽名與預設參數：

print(*objects, sep=' ', end='\n', file=sys.stdout, flush=False)
  • *objects：可接收多個輸出物件，物件之間預設以 sep 分隔。
  • sep：多個引數之間的分隔字串，預設為一個空格 ' '。
  • end：輸出結束時自動附加的字串，預設為換行符 '\n'。
⚙️ 直譯器執行邏輯圖解：print() 資料流寫入 sys.stdout 流程
SOURCE CODE
L1: print("Hello World")
L2: name = "Alice"; print(name)
"Hello World"
TERMINAL (sys.stdout) ● LIVE
Hello World_
[Buffer]: Auto-flushed with '\n'
[Step 1/2]: 直譯器讀取常數面額 (Literal) "Hello World" ➔ 轉換為字元流封包，沿 sys.stdout 管道推送 ➔ 附加預設 end='\n' 換行符後刷新輸出至控制台。

範例 1：簡單的字串輸出

print("Hello World")

控制台輸出結果：Hello World

範例 2：輸出變數引數與多引數分隔

name = "Alice"
age = 20
print(name, age, sep=" : ")  # 自訂分隔符

控制台輸出結果：Alice : 20

二、變數定義與記憶體模型

1. 變數本質：識別碼與堆疊記憶體參照

在 Python 中，變數並不是裝載資料的實體容器，而是一個識別碼（Identifier）。當執行賦值敘述（如 x = 10）時，直譯器會遵循以下順序處理：

  1. 右式求值（Right-Hand Side Evaluation）：首先在堆疊記憶體（Heap Memory）中建立值為 10 的 int 物件，並分配一個獨一無二的記憶體位址（如 0x10A4）。
  2. 識別碼繫結（Identifier Binding）：在當前命名空間（Namespace）的符號表（Symbol Table）中建立識別碼 x，並將其指標（Pointer）指向位址 0x10A4。
⚙️ 直譯器執行邏輯圖解：符號表 (Symbol Table) 與堆疊記憶體參照 (Heap Reference)
SYMBOL TABLE (Names)
x ➔ 0x10A4
Addr: 0x10A4Type: int
Value: 10
ref_count: 1
Addr: 0x20B8Type: str
Value: "Hello"
ref_count: 0
[Step 1/3]: 執行 x = 10 ➔ 堆疊記憶體配置 int 物件 (10) 於位址 0x10A4 ➔ 符號表建立識別碼 'x' 並指向位址 0x10A4 (ref_count: 1)。

2. 變數命名規範與語法約束

  • 組成字元限制：僅能包含大小寫英文字母（A-Z, a-z）、數字（0-9）與底線（_）。
  • 開頭字元限制：識別碼嚴禁以數字開頭（例如 1num = 5 會引發 SyntaxError）。
  • 保留字迴避：不可使用 Python 保留關鍵字（Reserved Keywords，如 if, def, class, for, import）。
  • 大小寫敏感（Case-Sensitivity）：age 與 Age 在符號表中被視為兩個截然獨立的識別碼。

範例 3：合法與非法變數命名示範

# 合法命名 (Valid Identifiers)
user_age = 25
_sys_status = 1
total_score_2 = 98.5

# 非法命名 (SyntaxError 語法錯誤)
# 2nd_user = "Alice"  # 錯誤：不可以數字開頭
# class = "Math"      # 錯誤：佔用 Python 保留關鍵字 'class'

範例 4 ~ 6：多重賦值、連鎖賦值與動態型別 (Dynamic Typing)

# 1. 多重賦值 (Tuple Unpacking 元組解構)
x, y, z = 10, 20, 30  # 同時建立 3 個物件並繫結至相應識別碼

# 2. 連鎖賦值 (Shared Reference 記憶體位址共用)
a = b = c = 100       # a, b, c 三個識別碼皆指向同一個整數物件 100 (id(a) == id(b))

# 3. 動態型別重新綁定 (Dynamic Re-binding)
data = 10             # data 參照 int 物件 (0x10A4)
data = "Hello"        # data 重新指向 str 物件 (0x20B8)，原 int 物件引用計數歸零觸發 GC (Garbage Collection)

三、輸入與型別轉換

1. input() 阻塞式輸入與顯式型別轉換

input() 執行時會暫停 Python 直譯器執行緒（進入阻塞狀態 Blocked State），並等待標準輸入流（sys.stdin）接收使用者敲擊鍵盤輸入的 ASCII/Unicode 字元流。

⚠️ 核心關鍵要點：

無論使用者輸入何種內容（即便輸入數字 25），input() 擷取後一律封裝為字串型態（str）。若直接對字串進行算術運算（如 "25" + 1），直譯器會拋出 TypeError。必須呼叫 int() 或 float() 進行顯式型別轉換（Explicit Typecasting）。

⚙️ 直譯器執行邏輯圖解：sys.stdin 字元流與 int() 顯式型別轉換過程
1. sys.stdin
Buffer Input:
'2','5'
Encapsulated as str
str: "25"
2. int() Engine Idle
Parsing ASCII '2','5'
Numeric Parser Ready
int: 25
3. Arithmetic (+1)
"25" + 1 ➔ TypeError
Type mismatch
[Step 1/3]: input() 從 sys.stdin 擷取 ASCII 字元流並封裝為 str 物件 "25" ➔ 若直接與數字 1 相加，會因型別不符引發 TypeError。

範例 7：字串輸入與字串拼接

name = input("請輸入您的名字: ")
print("Hello, " + name + "!")

範例 8：輸入轉型與算術運算

age_str = input("請輸入年齡: ")
age = int(age_str)  # 顯式型別轉換為 int 物件
print("明年年齡:", age + 1)

四、格式化輸出

格式化字串用於將多個不同資料型態的變數整合為特定結構的字串。Python 3.6+ 推行的 f-string（Formatted String Literals）會在執行期（Runtime）將大括號 {} 內的運算式進行求值與變數內插替換（Variable Interpolation），執行效率優於傳統的 % 與 str.format() 方法。

⚙️ 直譯器執行邏輯圖解：f-string 執行期變數內插 (Variable Interpolation) 過程
"Alice"
21
f"名字: {name} , 明年: {age + 1} "
[Step 1/3]: 直譯器剖析 f-string 結構 ➔ 識別出靜態字串片段與兩個動態運算式插槽 {name} 與 {age + 1}。

範例 9 & 10：格式化寫法對比 (str.format 與 f-string)

name = "Alice"
age = 20

# 寫法 1：str.format() 方法
print("名字:{}, 年齡:{}".format(name, age))

# 寫法 2：f-string 變數內插 (推薦：執行效率最佳且語法最直觀)
print(f"名字:{name}, 明年:{age + 1}")

# 寫法 3：格式化控制符 (例如浮點數保留兩位小數)
pi = 3.14159
print(f"圓周率: {pi:.2f}")  # 輸出: 圓周率: 3.14
